The OpenGL 1.1 normal contract maps the full signed integer range linearly to [-1,1]: (2c+1)/(2^bits-1). Integer zero therefore maps to a small positive value. Widening the signed 32-bit value before arithmetic preserves the correctly rounded binary32 result.
