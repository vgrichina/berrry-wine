Run: `scratch/runs/20261117-sims-owned-native-typeinfo-factory-dispatch-integration/result.json`.

The native SYSTEM lookup now maps IDispatch/ITypeInfo/ITypeLib to the standard PSDispatch/PSTypeInfo/PSTypeLib classes, with genuine registry overrides taking precedence. Public CoGetClassObject creates the x86 IPSFactoryBuffer. Its class-specific factories reject other IIDs, preserve aggregation through the controlling unknown, and keep IRpcProxyBuffer's IUnknown independent. No Sims-specific registry mapping is seeded.

The owned byte channel now transports bounded typed descriptor graphs, counted strings, Automation values, nested type interfaces and reference attachments. ReleaseTypeAttr/ReleaseFuncDesc/ReleaseVarDesc/ReleaseTLibAttr consume exact per-proxy leases, retaining their controlling unknown until release. Original native descriptors and output references are released by the native owner. Reply references transfer to the authenticated caller before completion and retire on cancellation, including completed replies never polled. All outputs validate before synchronous publication; replaced BYREF owners release afterwards because native Release may call back. Native WAT remains the metadata and Invoke implementation.

Inherited IDispatch contracts are integrated into custom typed interfaces obtained from the real native type library. An actual x86 OpenCAB control returns ISetupCABFile; its inherited GetTypeInfo/GetIDsOfNames/Invoke and custom File method roundtrip, including embedded-NUL BSTRs. Two separate x86 instances with independent memories and heap positions repeat the typeinfo/library/derived-interface calls. Executing native ReadFile cancellation, nested calls, disconnect, retirement, unpolled replies, malformed references/graphs/late outputs, descriptor double release and native flags/frame restoration are covered. The focused final proof reports zero owned allocations, objects, descriptors, exports, requests and pending frames.
