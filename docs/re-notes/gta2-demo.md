# Grand Theft Auto 2 Wild Demo

## Exact artifacts

- Original distribution: `gta2demo.exe`, 12,972,175 bytes, SHA-256
  `f8fc0a9653932f008a03e56ea892fb31dbeb98d228cc4df61b910bcb35d08d21`.
- Installed `gta2.exe`: 2,893,824 bytes, SHA-256
  `97ad743b6ec9ea1be95282053c3127084acd764a7f37a3e57e2268af52d02ae3`.
- Installed `mss32.dll`: SHA-256
  `0974b244354a5d13e0711db15430c05f7949dc279b63897146f304d1401153fc`.

The installed program tree has 73 payload files. InstallShield also writes
`uninst.isu`, making 74 files beneath `C:\Program Files\GTA2 DEMO` after a
complete run.

## Authentic installer chain

`gta2demo.exe` is a PackageForTheWeb self-extractor. Its LZ32 calls unpack 92
split `data*.cab` volumes and the rest of Disk1 under
`C:\WINDOWS\TEMP\pftw3~tmp\Disk1`. It then calls:

```text
CreateProcessA(NULL, "\"C:\WINDOWS\TEMP\pftw3~tmp\Disk1\Setup.exe\" /SMS", ...)
```

The emitted 73,728-byte `Setup.exe` has SHA-256
`5656e87da0641c9dcfcd0ee8949ce72b3fa6a7d0e8b1fd985a16f6bd6c34ce52`.
It expands the InstallShield engine and invokes
`C:\WINDOWS\TEMP\_ISTMP1.DIR\_INS5576._MP` with `WinExec`. That engine has
SHA-256
`a8657371f03e2e66db951c3dcd3aeb42c576894908ca2eb1b3806aa0404cb083`.

Wine Assembly currently emulates one Win32 process and does not execute either
child-process request. `test/test-gta2-demo-installer.js` therefore resumes the
two files emitted by the preceding authentic stage as separate emulator runs.
It does not use Unshield. The engine receives the command line generated by
Setup's `_INS0432.INI`, its actual wizard pages are clicked, its cabinet copy
runs, and acceptance requires this final text:

```text
The GTA2 Installer has finished installing GTA2 on your computer.
The GTA2 Installer can now launch GTA2.
```

Unshield was used once while diagnosing a split-volume boundary issue and to
compare file layouts. That extraction is neither the prepared collection path
nor installer acceptance.

## Compatibility findings

- The self-extractor needs ordinary-stream `LZCopy` plus `LZOpenFileA` support
  for write/create flags.
- The wizard's DirectX check creates CLSID DirectMusic
  `{636B9F10-0C7D-11D1-95B2-0020AFDC7421}` as an availability probe.
- `d3ddll.dll` sleeps for 500 ms from `DllMain`. Returning to the caller at that
  cooperative yield abandoned its live initializer stack; the loader must
  resume bounded Sleep yields before restoring the outer registers.
- GTA2 queries IID_IDirectDraw4 `{9C59509A-39BD-11D1-8C4A-00C04FD930C5}`
  and calls slot 27, `GetDeviceIdentifier`. Aliasing it to the old 24-slot
  IDirectDraw2 table dispatched into the next interface and corrupted ESP.
  IDirectDraw4 and IDirectDraw7 now have 28- and 30-slot extension vtables.
- The game queries `IDirectDrawGammaControl` and snapshots/sets its gamma ramp.
- `mss32.dll` must be preloaded; `d3ddll.dll` and `dmavideo.dll` are discovered
  dynamically from the mounted installed tree.

  --max-batches=4500 --batch-size=1000 \

otherwise select a cached front-end surface because this title creates many

## Shared lazy synchronization A/B (2026-09-29)

The [hardware browser benchmark](../lazy-sync-game-results.md) reached gameplay
with two live guest workers throughout measurement. Lazy OFF / ON measured
29.86 / 29.79 FPS and about one readback per frame in both modes. ON leaves
one armed Lock untouched per frame, but presentation still needs its readback
and GPU backend fence calls increase from one to two. A later call-stack trace
confirmed only one guest fence request per frame: the other backend call is
inside queued-flip replay. Publication adds its own wait, measured separately.
The helper recorded no lazy
surface touches, so this is coexistence coverage, not a real-game test of
foreign-thread pixel access. This initially remained opt-in; the subsequent
shared-WebGL default rollout provides `?no-lazy-sync` and the live **Lazy sync**
debug checkbox as opt-outs. The retained-GDI-pointer limitation still applies.

## GTA2 Demo Manager property sheet (2026-11-21)

`Program_Executable_Files/gta2 manager.exe` is a statically linked MFC
`CPropertySheet` wizard (Back / Next / Cancel). Its pages are 264x282 DLU
dialogs (language + text speed, video, audio...). It comes up at startup, so
no clicks are needed:

```sh
E="test/binaries/candidates/gta2-demo/installed/Program_Executable_Files/gta2 manager.exe"
node test/run.js --app=gta2_demo --exe="$E" --screen=1024x768 \
  --quiet-api --max-seconds=30 --no-close --png=/tmp/mgr.png
```

**CLI vs browser:** the browser never loads a real `comctl32.dll` (no default
path in `lib/dll-registry.js`), but the CLI loads
`test/binaries/dlls/comctl32.dll` when that file exists, and the bug does not
reproduce there. To see what the browser sees, remove that file from your
worktree's `test/binaries/dlls/`.

With the builtin WAT `PropertySheetA` the sheet showed only the three buttons
over an empty gray area. That was three separate gaps, all fixed in
`fix/gta2-options-page`:

1. **No COMCTL32 dialog resources.**
   - MFC's `AfxGetPropSheetFont` (inlined near VA `0x439e97`) calls
     `FindResourceA(GetModuleHandle("COMCTL32.DLL"), 1006 IDD_PROPSHEET or
     1020 IDD_WIZARD, RT_DIALOG)`. It then copies that template's face and
     point size onto every page template.
   - The builtin COMCTL32 image was header-only, so the lookup returned 0. The
     uninitialized point-size WORD then made `dlg_load` measure huge base
     units, with controls placed at e.g. `16167,9728 -32251x14336`.
   - Fix: `$comctl32_install_resources` (08-pe-loader.wat) copies both stock
     templates (8pt MS Sans Serif) into the image at RVA 0x400. `$push_rsrc_ctx`
     now honours a static system module's own resource directory.
2. **No WH_CBT HCBT_CREATEWND for the frame and pages.**
   - MFC arms `AfxHookWindowCreate` (`SetWindowsHookExA(5, 0x42e546)`) before
     `PropertySheetA`, and again in each page's PSPCB_CREATE. It attaches the
     CWnd from the hook.
   - Without the hook, `AfxDlgProc` never reaches `OnInitDialog`. The app's
     setup never ran: it hides buttons 1125-1129, sets "Language" and
     "Text Speed: 3", fills the trackbars, and so on.
   - Fix: `$propsheet_cbt_create` (09c3a-dialog-runtime.wat) runs the CBT
     chain for the builtin frame and each page.
3. **Fixed 420x228 page area.**
   - A 282 DLU page lost its lower half under the buttons.
   - Fix: `$propsheet_measure_pages` sizes the page area to the largest page
     template, never smaller than the old frame.

The builtin sheet is still wizard-style even for tabbed (non-`PSH_WIZARD`)
headers; tabbed mode is not implemented. Regression test:
`test/test-property-sheet-mfc-host.js`. Evidence:
`scratch/runs/20261121-gta2-options/` (before, after, Next/Next/Back).
