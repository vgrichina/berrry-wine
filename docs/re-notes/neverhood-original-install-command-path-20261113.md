## Dispatch, OS gate and installed-state split

`0x405380` handles WM_COMMAND. For ID **105** it calls IsWindowEnabled on the stored Install HWND; only a nonzero result calls **0x404b60 at 0x4053df**. This is the original named/default-button route; no coordinates are needed. A forged command to a disabled button does not pass this check.

`0x404b60` constructs the progress object, clears uninstall switch/global restart bookkeeping, zeroes an OSVERSIONINFOA in the setup object, sets its length to **0x94**, and calls **GetVersionExA at 0x404bb2**. It does not check that API’s return value. Resource 7000 declares Win9x tuple **(4,0,0)** and alternative-platform tuple **(0xffffffff,0,0)**. Platform 0 selects string **44** and exits; platform 1 compares major, minor and build independently, using unsigned comparisons, against the first tuple. Other platforms take the second tuple; its major -1 is rejected with string **46**. The code is not a general lexicographic version comparison. String **45** on the Win9x rejection literally reads `empty`; 44/46 require Windows 95. Do not change version state to force passage.

After the gate, calls **0x409530(FALSE)** and **0x409de0** must return nonzero before progressing. The first reads `Data Drive` or derives the setup module directory and writes that default REG_SZ; the second writes the product PID. Thus Install already has real HKLM mutations before copying. Missing/read-only registry behavior cannot be replaced by seeded values.

At **0x404ca7**, `0x409700` checks `Installed`:

- **Fresh/uninstalled:** `0x404d43` checks again, conditionally calls **0x404ad0** unless the recorded platform is 2, then calls **0x4049f0** for directory selection. DX raw return **-12** goes to string **36**, `Installation was canceled.` Other negative raw values go to generic failure; nonnegative values continue. The platform-2 skip exists, but the unchanged resource’s earlier OS gate rejects its declared tuple.
- **Already installed:** the branch calls **0x4045b0** (also used by Play; its body is outside retained windows), may force source-directory refresh, verifies source `Data Drive + setup\nhc.exe` through **0x409cb0 → 0x407240**, and can open source-location dialog **116** via **0x404910**. Accepted source choice is copied to setup field `+0xcc`. It then writes Data Drive, reparses resource 7000, reads Installed Directory, and conditionally checks DirectX before joining the copy dialog. It does not automatically open dialog 114 on this branch. The result and internal behavior of 0x4045b0 remain unknown here.
