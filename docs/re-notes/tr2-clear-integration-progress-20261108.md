## First new defect and tested production repair

`SurfacePublicationJoin.publication` previously called
`account('uncovered-publication-writer')` whenever its epoch was temporarily
unavailable. That permanently moved every pending source into the discard
ledger even if the writer touched unrelated watched memory and the source
remained immutable. A later complete canonical read could never qualify that
source because the key was already marked seen. The native pre-input ledger
provides the concrete new integration symptom; the focused regression isolates
this generic behavior from legitimate source-overlap rejections.

The scoped change in `lib/render-worker.js` keeps qualification blocked during
the writer and calls ordinary `account()` to discard only concretely rejected,
superseded or invalidated sources. An otherwise valid source stays pending.
A later qualification still requires a fresh canonical read, exact owner and
request, unchanged host/page proof, transfers and display publication. An
unqualified cached decode cannot acquire a proof. Retirement still accounts
for every remaining source. Clear's host-version invalidation and requirement
for a next fresh flip are preserved by the clear regression after this repair.
