## Contract and generated probe

Its EMS flag is ignored on non-EMS systems. The same reference distinguishes GlobalCompact as the largest available block. The current `src/09e-win16-api.wat` implementations both return only `(WIN16_SEG_MAX - win16_next_seg_get()) * 65536`, omitting freed storage that the real allocator can reuse. The generated fixture below confirms a reusable-block accounting defect, **not a demonstrated cause of the original warning**.

It saves DX:AX before allocation, after a 128 KiB allocation, after free, after reallocating that same capacity, and after a second free. It also saves GlobalCompact and SP.
