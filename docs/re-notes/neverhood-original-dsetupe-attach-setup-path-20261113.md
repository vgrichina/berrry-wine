## Export entry, source paths and configuration

The wrapper's sealed call **0x1000122c → [wrapper 0x10006060]** forwards `(HWND, source setup directory, 0x10000a3f)` for ordinary Win9x; it can OR 0x80 for existing-install state. DSETUPE **0x100034b0** reads all three arguments and proves the matching ABI with **`ret 0x0c` at 0x10003845**. Zero flags default to **0xa3f**. Any bit of **0xa27** expands to all of 0xa27, and **0x1000** is always ORed; the ordinary flags become **0x10001a3f**. No input/result is supplied by this investigation.

The first API **inside the export** is **GetVersionExA at 0x100034eb**, with OSVERSIONINFOA size **0x94**. Its BOOL is unchecked. Exact platform 1/major 4/minor 0/low build WORD **950** sets **0x1000fa0c=1**, otherwise zero. This is an equality used in later component-copy decisions, distinct from the wrapper's pre-release classification. GetWindowsDirectoryA and GetSystemDirectoryA populate separate global paths. A nonempty source argument is copied verbatim to **0x10010148**. Missing/empty source instead uses GetModuleHandleA(NULL), GetModuleFileNameA and GetShortPathNameA via **0x100038d0**, then removes the executable basename. The supplied Neverhood source path selects the direct-copy branch.

Helpers **0x10003890/3850** remove/add trailing backslashes using CharNextA. The system path also builds a `VMM32\` path. **0x100035f4 → 0x100033d0** opens **HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion**, queries **ProgramFilesDir** into a 0x104-byte buffer and closes the key. Those CreateDirectory/GetShortPathName results are not checked before it returns TRUE. Thus even the setup preflight mutates directories; registry-query success does not prove usable output paths.
