Ten per-context tables start with one zero entry. Mapping is initially disabled, giving identity transfer. Maximum table size is 256; the six index-addressed maps require a power of two. Component maps clamp float entries and normalize unsigned entries. Color-index entries retain fractions and unsigned integer values; stencil entries round to the nearest integer. Unsigned getters normalize [0,1] to their output width; values outside that interval are unspecified by GL1.1.

RGBA transfer scales and biases before component table lookup. Color-index texture upload instead shifts/adds numeric indices and independently masks four index-to-component table addresses, regardless of MAP_COLOR. The renderer remains RGBA; storing/querying I_TO_I and S_TO_S does not add color-index framebuffer or stencil pixel consumers. Existing unsupported exports stay unsupported.

Tables and sizes are excluded from attribute stacks (table 6.16). PIXEL_MODE_BIT restores transfer enables/scales. List setters capture client buffers but modify server tables only on execution; getters execute immediately. Queued commands own setter bytes.

Native table storage preserves unsigned index words in doubles; canonical index upload slots retain numeric indices until execution. Index transfer uses 32 integer bits and eight fractional bits, with zero-fill shifts and independent table masks. Context teardown frees the tables. Native query output uses exact 2-byte or 4-byte elements after complete sparse-span validation.
