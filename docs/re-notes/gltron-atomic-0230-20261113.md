## Run-local repair and focused tests

`control.py` publishes each request to an exclusive random temporary file,
flushes and fsyncs it, then renames it into the ready namespace and fsyncs the
directory. A permanent exclusive identity reservation refuses publisher
reuse. The consumer ignores temporary files and renames each ready request
to a permanent claim **before** parsing or sending. Duplicate claimed IDs
cannot send again; malformed JSON and mismatched/invalid commands receive
explicit invalid receipts without taking down the consumer. Commands preserve
their original identity, and actual runtime replies create separate ACKs.
Pending or lost requests are never automatically resent.

Each finite key pair arms its UP timer before DOWN under the send lock. The
UP timer runs independently of request polling and ACK handling; cleanup also
attempts release of held keys. Every actual key pair in this run received both
ACKs (14 key ACKs total). A timer duration is a host send interval, not a
claim about guest-observed hold duration.

`tests-complete.log` records five passing tests: partial publication ignored
until rename; duplicate publication/consumption refused; malformed and invalid
identity handling; ACK versus terminal UNKNOWN/noReplay; an actual exited
child with a broken stdin pipe; and signal cleanup with a real substituted
child, actual wait and both separate EOFs. The earlier four-test run had a
test teardown BrokenPipeError on closing the already-broken pipe; it is
preserved in `tests-final.log`, and the corrected teardown passes.

`executed-control.py` preserves the exact helper used for the game. The final
`control.py` additionally distinguishes SENT_UNCONFIRMED from terminal UNKNOWN
and handles TERM/INT through cleanup. Those final changes passed the five-test
suite, including the real signal/EOF test; they were not rerun against a second
