`tools/q3-native-launch-client.py` is the production replacement entry for

historical task or input file is rewritten. For a separately authorized future

and send JSON lines `{"command":{...},"review":"..."}` through its stdin.
Allocation, provisioning, and independent box watchdog remain outside this
entry; it does not authorize another original. The former standalone command
entry bypasses this owner and must not be used for the managed session.

The first observed owned launch exit, signal or stdio EOF closes admission
permanently. A direct process poll also checks before each command spawn. The
observer performs an actual parent wait independently of pipe draining; a pipe
holder cannot conceal child termination. Pending local command transport is
