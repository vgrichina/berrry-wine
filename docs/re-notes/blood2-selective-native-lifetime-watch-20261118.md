at a JS boundary; a scope cannot be rearmed. The actual native observing
thread, PC, prior block, registers, stack, object and DLL rows accompany each
witness. These identify an observation interval, **not an exact writer or a
concurrent writing thread**. A page notification can precede the store; the
following boundary can therefore be the first witness.
