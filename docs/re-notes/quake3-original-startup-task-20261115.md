## Measurement route

`tools/quake3-startup-task-controller.cjs` composes the released original controller
in memory, retaining its three-second connection, registered launch, capture,
queued-input, owner, visibility, finite independent UP and irreversible Quit rules.
The diagnostic composition adds only installation of timing bindings, this run's
qualification destination and an export of the original browser entry point.
Exact source anchors fail closed. The original helper is not edited.

The diagnostic server serves the actual production d3d render Worker with narrowly
anchored timing statements around initial script execution, its ordinary serialized
message envelope, native renderer initialization and ordinary frame publication.
Declarations retain their original global lexical scope. Both original and served
source hashes are recorded before server start; the transformation is recoverable
from Git plus the diagnostic tool. No source bundle is retained. Actual Manager,
GL adapter and current interpreter module remain the production implementations.

The pre-start Worker instrumentation measures public importScripts, WASM dispatch
and native GL calls. It preserves arguments, receiver, return value, promise
identity and thrown exception. It issues no GL call or synchronization on its
own and attaches no promise settlement handler, preserving unhandled-rejection
behavior. The server instruments the existing d3d instantiate awaits and host.js
compile awaits in place, without adding awaits or promise reactions; their actual
source hashes are separately pinned. An asynchronous envelope is never treated
as continuous native occupancy.
No guest export is called by the observer; native initialization is timed only
where the production code already calls it.

The exact 47-byte snapshot query remains unchanged. Its wrapper records entry,
original body start/completion and wrapper completion, with the body samples
emitted after the call. Binding JSON overhead is outside the original body.
Metadata contains sequence, stage, clocks, endpoint/owner integers when actually
available, target and session. There are no GL arguments, GL results, pixels,
command buffers, guest-memory, source or media payloads in timing records.

The first sixteen asynchronous/message/script envelopes announce entry before
executing. Synchronous native/import/GL call samples are emitted after return,
so binding overhead is outside their measured call interval; a native call that
never returns consequently has missing completion evidence. The first sixteen
calls of each kind and later calls lasting at least five milliseconds retain pairs;
counts/maxima summarize quicker calls. A hard 30,000-event per-context limit
bounds output; the last event explicitly announces overflow, with subsequent
drop totals unknown outside the target. The snapshot wrapper always
attempts its samples, subject to that same limit. Incomplete or ambiguous evidence
cannot establish queue/body attribution. Worker monotonic durations are separate
from host/Worker epoch differences, which retain the established two-millisecond
sampling tolerance without clamping negative residuals.

CDP operation metadata identifies request send/response, Debugger source requests
and scriptParsed receipt. Inspector dispatch itself is not measured by those
receipts and remains null unless separately demonstrated. No Chrome task trace
is currently collected. A message/instantiate envelope overlapping send is not
proof that a native call blocked inspector dispatch for the full envelope.
