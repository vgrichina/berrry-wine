Design:
- Search conventional guest addresses 0x10000..0xA0000. These are DOS/VGA ABI
  bounds, not invented Wasm region addresses. Low DOS/BIOS data and the video
  aperture are excluded. virtual_range_edge_locked respects committed maps,
  uncommitted reservations, and the affine direct window. If an image's direct
  window covers the conventional range, allocation truthfully fails.
- Publish sparse ownership while holding LOCK_VIRTUAL_MAP; back it through
  virtual_map_commit_locked with coalescing OFF so neighboring allocations
  cannot become one release unit. Backing remains allocator-selected.
- This initial allocator reserves whole 4KB pages per block. Descriptor limits
  and GlobalSize expose the paragraph-rounded requested size. Finite capacity,
  fragmentation, selector, reservation-table and backing failures return zero.
  Zero-byte allocations are explicitly rejected; exact historical Windows
  zero-size behavior is not established by these sources.
- Consecutive protected selectors describe 64KB pieces; the head retains DOS
  ownership separately from ordinary Win16 arena flags. Free accepts only the
  exact live owning selector, never a paragraph, alias, tail or ordinary global
  selector. Release returns the backing reservation and restores arena slots.
  GlobalFree routes DOS owners to the same release path and propagates failure.
- GlobalReAlloc of a DOS owner remains fail-fast (diagnostic CA161184), since
  its existing high-arena growth/copy behavior would invalidate the real-mode
  address. This is an explicit unsupported operation, not a successful stub.
  No DOS interrupts, DPMI host, real-mode execution or general DOS emulator
  support is claimed. Generic selector mutation/lifetime changes are outside
  this bounded implementation.
