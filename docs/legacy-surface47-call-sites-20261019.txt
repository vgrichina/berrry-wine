Scope and manual route review:
- Each row is one textual com(...) call site; loops execute some rows repeatedly.
  Generic helper rows list all possible acquired interface versions. Surface7
  primary IUnknown pointers remain Surface7; the older views retain their own ABI.
- DirectDraw versions are recorded from factory/IID acquisition in the candidate,
  keyed by returned vtable. Shared SetDisplayMode requires version1 ->4 arguments,
  versions2/4/7 ->6; the precheck never infers this from the supplied argument count.
- Texture2 QueryInterface/AddRef/Release use3/1/1 arguments despite generic metadata5.
  QI delegates through d3dim_qi family5 with saved/restored dispatcher ESP/EAX;
  Release delegates to surface lifetime release; AddRef uses shared COM helper.
- EnumDisplayModes uses callback(desc,context), RET8+return=12; EnumSurfaces and
  EnumAttachedSurfaces use callback(surface,desc,context), RET12+return=16.
  Candidate captures live descriptor data before callback returns. EnumSurfaces'
  288-byte iterator frame is removed by dd_enum_surfaces_finish; outer API frame
  is24 bytes. Callback cancellation and exact final caller ESP remain asserted.
- Surface Lock has five arguments at every version; desc108 vs124 changes pointed
  data only. Unlock has two arguments: Surface1/2/3 data pointer vs Surface4/7 rect.
- Surface Initialize is slot23 with three arguments and16-byte cleanup. Slot21
  is GetPixelFormat with two arguments; published method-name assertion protects
  the Initialize probe separately from its argument count.
- Surface SetSurfaceDesc slot39 has three arguments at versions3/4/7. Versioned
  description size changes pointed data, not stack count. GetCaps/description,
  attached caps, IUnknown and bad-IID return expectations remain unchanged.
- QI-owned references, enumeration-owned references, retained-view releases,
  mip/flip child ownership and allocator-exhaustion checks were traced through
  production handlers; no return assertions were changed by this call-site audit.
- This matrix is source evidence, not a guest PASS. No runtime was launched.
