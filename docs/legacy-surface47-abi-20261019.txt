Implementation
Native Surface4 and Surface7 have separate generated 45/49-slot tables, appended
registry entries and API IDs4581..4589. The nine new tail methods retain named
crash_unimplemented handlers. Existing VB interfaces keep their converter ABI.
DirectDraw4/7 creation returns the matching native surface view. GetCaps uses
16-byte DDSCAPS2 without looking for a nonexistent size word; legacy Surface1/2/3
still writes four bytes. GetSurfaceDesc/Lock use the interface's108/124-byte size,
and reject a mismatched dwSize. SetSurfaceDesc selects the same input shape.
Initialize remains DDERR_ALREADYINITIALIZED, without reading a descriptor.
Unlock continues the existing completion path: its argument is not dereferenced,
so native RECT and legacy data-pointer callers do not get reinterpreted.

Surface QI recognizes all16 IID bytes for Surface1/2/3/4/7 and IUnknown; unknown
surface IDs fail E_NOINTERFACE. Surface views use independent auxiliary counts
and canonical primary IUnknown identity. Texture-to-surface and device-to-v1
QI route through this surface classifier. Other old device/texture IID matching
is outside the complete-IID claim. Surface wrapper exhaustion returns failure
instead of changing the existing primary vtable. Retrieval/enum callbacks use
the caller's surface version and acquire an owned reference. Native DirectDraw
EnumSurfaces/EnumDisplayModes/GetDisplayMode descriptor shapes are also updated.

No cube/storage success is invented: when DDSD_CAPS selects the caps field,
native CreateSurface rejects nonzero caps2/caps3/caps4 with E_NOTIMPL
(0x80004001) before allocation and clears its output pointer. SetSurfaceDesc
likewise rejects selected nonzero extended caps. With DDSD_CAPS absent these
unused fields are ignored; CreateSurface also ignores the unused caps1 word. Native
GetAttachedSurface requests with nonzero extended caps fail DDERR_NOTFOUND.
Zero extended outputs describe only allocations whose extended capabilities
were not accepted. No DX_SURF_META word was repurposed; no renderer capability
bits were changed. Cube groups, independent faces, mip/face selection, rollback,
allocation-failure injection and sampler/upload/orientation remain follow-up work.
