Quake II Demo (version 3.14, Win32) -- where these files come from
====================================================================

Every game file mounted here is extracted, byte for byte and unmodified,
from id Software's own demo installer:

  q2-314-demo-x86.exe   39,015,499 bytes
  MD5   4d1cd4618e80a38db59304132ea0856c
  SHA-1 5b4dedc59ceee306956a3e48a8bdf6dd33bc91ed

Official download (id Software's FTP, the original distribution point):

  ftp://ftp.idsoftware.com/idstuff/quake2/q2-314-demo-x86.exe

That server is no longer online. The same file, from the GWDG mirror of
id's FTP tree (check it against the hashes above):

  https://ftp.gwdg.de/pub/misc/ftp.idsoftware.com/idstuff/quake2/q2-314-demo-x86.exe

Only the files the game needs to run are published: quake2.exe, ref_gl.dll,
ref_soft.dll, baseq2/gamex86.dll, baseq2/pak0.pak and the player models in
baseq2/players/. The 3Dfx/PowerVR drivers and the HTML manual are left out.

id's license for the demo travels with it as C:\DOCS\LICENSE.TXT, as its
section 3 requires. The one file that is not id's is C:\BASEQ2\CONFIG.CFG,
this site's default controls (WASD + mouse look); the game rewrites it
when you change a setting.
